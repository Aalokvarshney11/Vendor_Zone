# VendorZone — Backend

Place your backend code (Express / Node / MongoDB) in this folder.

### Frontend API Expectations:
- **Default Port:** `http://localhost:5000` (or `http://localhost:3000` depending on your `.env.local`)
- **Authentication:** JWT in `Authorization: Bearer <token>`
- **API Reference:** Check the endpoint table in `../README.md` or `../lib/api.js`.
